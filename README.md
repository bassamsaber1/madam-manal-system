هذا المشروع مجهز بالكامل للرفع المباشر على **Render** أو **GitHub** والتشغيل السلس بـ Build واحد وبدون الحاجة لربط خوادم معقدة.

## 🛠️ كيفية التنزيل والتشغيل محلياً (Local Setup):
1. قم بفك الضغط عن هذا الملف.
2. افتح مجلد المشروع في الـ Terminal.
3. قم بتشغيل أمر تثبيت الملحقات:
   ```bash
   npm install
   ```
4. الآن، قم بتشغيل السيستم في بيئة التطوير:
   ```bash
   npm run dev
   ```
5. افتح المتصفح على الرابط: `http://localhost:3000`

## 📁 ملف البيانات all.txt:
* ستجد ملف البيانات المدمج في المسار التالي: `src/data/all.txt`
* يمكنك إضافة آلاف السطور بداخله بنفس الصيغة المعتمدة:
